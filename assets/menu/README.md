# 타이틀 배경 에셋 — 출처와 재생성 방법

제출 요건의 "AI 활용 기술 문서"가 **에셋 출처**를 요구하므로, 여기서 한 곳에 적어 둔다.
로고 쪽은 `assets/logo/README.md` 에 따로 있다.

## 출처

| 파일 | 무엇 | 출처 |
|---|---|---|
| `source/title-bg-1672.png` | 원본 1672×941 | **ChatGPT 생성**, 2026-08-09 |
| `title-bg.png` | 타이틀 배경 418×235 | 원본을 `scripts/bg-snap.mjs` 로 가공 |

> ⚠ 생성형 AI 산출물이다. 게임 **안**에는 AI 가 없고(설계 원칙), AI 는 개발 과정에만 쓴다는
> 것과 별개로, 이 그림은 AI 가 만들었으므로 기술 문서에 그렇게 적어야 한다.

## 재생성

```bash
node scripts/bg-snap.mjs assets/menu/source/title-bg-1672.png --grid 418 --out assets/menu/title-bg.png
```

- `--grid 418` — 임의값이 아니라 **원본이 그려진 격자**다. 1672 / 418 = 도트 4.00px 로 정확히
  떨어진다. `--probe` 가 후보를 훑어 준다 (209 / 239 / 418 / 557). 209·239 는 등대와 배 등불이
  뭉개지고, 557 은 격자는 맞지만 용량만 커진다.
- **격자를 벗어난 값을 쓰면 안 된다.** 356(게임 캔버스와 같은 해상도)으로 줄이면 도트가
  4.70px 이 되어 한 블록이 두 도트에 걸치고, 파도 소용돌이의 1도트 선이 끊긴다.
- 1.7MB → 171KB. 색은 60,637 → 13,488.

## 화면에서

`src/menu/menu.css` 의 `#screen-title` 이 배경으로 깐다. **`image-rendering: pixelated` 를
빼면 안 된다** — 브라우저가 보간하면 4px 도트가 흐려져서 로고(픽셀)와 배경(뿌옇게)이 따로 논다.

타이틀 섹션에만 걸려 있으므로 `▶ 시작하기` 로 섹션이 닫히면 저절로 사라지고, 그 아래에서
계속 돌던 절차적 배경(`#bg` 캔버스 · `scene/pixelbg.js`)이 컷신을 이어받는다.
그림 위에서 별과 달빛만 살아 움직이는 것은 `src/menu/screen.js` 의 오버레이 캔버스다.
