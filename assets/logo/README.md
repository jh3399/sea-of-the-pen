# 로고 에셋 — 출처와 재생성 방법

제출 요건의 "AI 활용 기술 문서"가 **에셋 출처**를 요구하므로, 여기서 한 곳에 적어 둔다.

## 출처

| 파일 | 무엇 | 출처 |
|---|---|---|
| `source/title-1536.png` | 1안 원본 1536×1024 | **ChatGPT (DALL·E) 생성**, 2026-08-08 |
| `source/mark-1536.png` | 4안 원본 1536×1024 | 〃 |
| `title.png` | 타이틀 로고 134×88 | 1안을 `scripts/logo-cut.mjs` 로 가공 |
| `favicon.png` | 파비콘 32×32 | 4안의 **배 부분만** 잘라 가공 |

4안 중 1안을 타이틀로 골랐다. 이유는 **금색이 들어간 유일한 안**이라서다 — 타이틀 화면의
강조색(`--accent`)과 `▶ 시작하기` 버튼이 금색이라, 로고에 금이 없으면 로고와 버튼이 따로 논다.
나머지 둘(양피지 / 원형 물결)은 채택하지 않았다 — 양피지는 밤바다 위에 크림색 사각형을 박고,
원형 물결은 배경의 픽셀 범선과 겹친다.

4안은 타이틀로 쓰기엔 획이 얇아 별밭 위에서 묻히지만, **배↑/펜촉↓ 수직 축**이 깔끔해서
파비콘으로 살렸다. 다만 파비콘에는 글자를 넣지 않았다 — 16px 에서 글자는 읽히지 않는다.
배만 남기면 돛 삼각형 둘 + 선체라는 실루엣이 그 크기에서도 산다.

> ⚠ 생성형 AI 산출물이다. 게임 **안**에는 AI 가 없고(설계 원칙), AI 는 개발 과정에만 쓴다는
> 것과 별개로, 이 그림은 AI 가 만들었으므로 기술 문서에 그렇게 적어야 한다.

## 재생성

```bash
node scripts/logo-cut.mjs assets/logo/source/title-1536.png --grid 160 --cut 40 --holes --out assets/logo/title.png --preview --zoom 4
```

```bash
node scripts/logo-cut.mjs assets/logo/source/mark-1536.png --crop 653,24,272,272 --grid 28 --cut 52 --holes --pad 32 --out assets/logo/favicon.png --preview --zoom 10
```

- `--grid 160` — 원본이 160×107 격자로 그려져 1536 으로 확대된 것이라 도트 하나가 9.6px 이다.
  정수가 아니므로 스크립트가 블록 경계를 실수로 잡는다.
- `--cut 40` — 배경(`#00051f`)의 최대 채널이 31 이다. 펜 몸통·글자 그림자는 이보다 밝아 살아남는다.
  4안은 배경이 `#000e2e` 라 최대 채널이 46 이어서 `--cut 52` 로 따로 잡는다.
- `--crop 653,24,272,272` — 4안에서 배가 있는 자리. 272 = 28 도트 × 9.7px 로, 원본 격자에 맞춘 값이다.
- `--pad 32` — 파비콘은 정사각이어야 브라우저가 늘이지 않는다. 내용(28×26)을 32×32 한가운데 둔다.
- `--holes` — `A`·`P` 안쪽 구멍까지 비운다. 안 주면 플러드 필이 바깥에서 못 닿아 남고,
  애니메이션 배경 위에서 살짝 다른 색 사각형으로 뜬다.
- `--preview` 가 내는 `title.preview.png` 는 **커밋하지 않는다** (`.gitignore`).
  남색/흰색/마젠타 체커 위에 나란히 얹어 헤일로와 먹힌 외곽선을 보는 용도다.

## 화면에서

`index.html` 이 상대경로로 참조하고(`assets/logo/title.png`), 크기는 `src/menu/menu.css` 의
`.game-logo` 가 정한다. **`image-rendering: pixelated` 를 빼면 안 된다** — 배경은 절차적으로
또렷하게 찍히는데 로고만 보간되어 흐려진다.
