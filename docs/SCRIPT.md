# 게임 대사 스크립트 — 『그리는 자의 바다 / Sea of the Pen』

> 실제 게임에 들어가는 대사 전문. 설정·기획은 [STORY.md](STORY.md) 참고.
> `[S-##]` 씬 ID는 `src/main.js`의 대사 배열 이름과 1:1로 대응시킨다.
> **[데모]** 표시 = 사전 과제 빌드 범위 / **[본선]** = 48시간 본선 확장 범위.
>
> 표기: `루` 주인공(플레이어) · `세렌` 뱃머리 정령 · `네일` 검은 함장 · `시험관` 항해사 협회
