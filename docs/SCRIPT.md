| 화자 | 대사 |
|---|---|
| 세렌 | 잉크는 바다에 있어. 400년 전부터. |
| 세렌 | 펜은 원래 다들 손에 있었고. |
| 루 | …그럼 진작에 다들 할 수 있었던 거네요. |
| 세렌 | 응. 아무도 확인 안 해봤을 뿐이야. |
| 세렌 | 너 빼고. |

▶ 루가 펜을 바닷물에 담근다. 펜촉에 금빛이 차오른다. 황금 펜이다.

| 화자 | 대사 |
|---|---|
| 세렌 | 아, 그리고 하나. |
| 세렌 | 너 그거 알아? |
| 세렌 | **너 이제 꽤 잘 그려.** |
| 루 | …소원 안 썼는데요. |
| 세렌 | 그러니까. |

▶ 루가 마을 아이들에게 펜을 하나씩 나눠준다. 아이들이 동요를 부른다.
▶ 이번엔 마지막 줄이 다르다.

```
(아이들)   형아가 하나 아우가 하나
           섬 끝에 살던 형제가 하나
           아우는 배를 다 못 그렸대요
           뱃머리 하나만 남았대요
           ―― 그래서 어떤 애가 대신 그려줬대요
```

| 화자 | 대사 |
|---|---|
| — | 펜은 손에 있었고, 잉크는 발밑에 있었다. |
| — | **『그리는 자의 바다』 — 그것이 보물의 이름이었다.** |
